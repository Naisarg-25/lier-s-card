Play Liar's Cards With Friends Online

Create a private room, share a 6-character code, and invite up to 5 friends to play the multiplayer bluffing card game — free, in your browser, no download needed.

🚀 How to Start a Game With Friends

  1. 1

    Go to the homepage

    Open liarscard.site in your browser. No account or download is needed.

  2. 2

    Enter your name

    Type a display name in the name field at the top. This is the name your friends will see at the table.

  3. 3

    Select "With Friends"

    Click the With Friends card. A prompt will appear asking for a room code if you want to join, or click "Or create a new room →" to generate a fresh private room.

  4. 4

    Share the room code

    Once in the lobby you will see a 6-character room code like KBVX72. Copy the code or use the "Copy Link" button to send a direct join link to friends.

  5. 5

    Friends join using the code

    Each friend opens the homepage, enters their name, selects "With Friends", types the room code, and clicks Join Room. Up to 5 additional players can join your room (6 players total).

  6. 6

    Host starts the game

    Once everyone is in the lobby, only the room host can press Start Game. The host can also remove players from the lobby if needed.

🔗 Joining a Friend's Room

Your friend will share either a room code or a direct link.

Via room code

  1. Open liarscard.site.
  2. Enter your name.
  3. Click With Friends.
  4. Type the 6-character code your friend shared.
  5. Click Join Room and you will appear in the lobby instantly.

Via shared link

If your friend copied the join link from the lobby, clicking it will take you directly to the homepage with the code pre-filled. Just enter your name and join.

🏠 What You Can Do in the Lobby

  • See who has joined: The player list updates in real-time as friends enter.
  • Add AI bots: The host can add AI bot players to fill empty spots, up to 6 total.
  • Remove players: The host can remove any player from the lobby before the game starts.
  • Copy code or link: Share the room code or a direct join link at any time.
  • Start the game: When you're ready, the host clicks Start Game. All lobby players are transferred directly into the game.

📋 Room Details

  • Maximum players: 6 (including the host)
  • Minimum to start: 2 players
  • AI bots: Can be added in the lobby to reach up to 6 total
  • Room code format: 6 uppercase alphanumeric characters (e.g. KBVX72)
  • Reconnect: If you accidentally close the tab, return to the site — your session will attempt to rejoin your room automatically

❓ Frequently Asked Questions

Do my friends need to create an account?

No. Liar's Cards is completely free and requires no account, login, or download. Just open the site, enter a name, and play.

Can I play across different devices?

Yes. Players on phones, tablets, and computers can all join the same room using the same room code.

What happens if someone disconnects?

Disconnected players have a grace period to reconnect. If they don't return in time, the game continues without them and their cards are removed from play.

Can the host leave mid-game?

The host role is set when the room is created. If the host disconnects, the game continues among remaining players.

How do I play with more than 6 people?

The current room limit is 6 players. For larger groups, consider running two separate rooms simultaneously.
